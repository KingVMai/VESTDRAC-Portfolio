# Public portfolio: privacy and publication scope

This repository is distinct from the private VESTDRAC development repository. It is not a software distribution.

The allowlist consists of a public README, three conceptual documents and two sanitized screenshots. No Python/JavaScript engine source, strategy internals, QuestMap, price histories, brokerage data, API keys, passwords, tokens, credentials, logs, database files, runtime checkpoints, private URLs or videos are to be published.

Removing image metadata does not remove information visible in pixels. Both images require a separate visual privacy review before their publication. If sensitive pixels are present, the image must be redacted or excluded.

This public case study describes the actual project scope and verifiable offline tests without claiming deployment, real transactions or profitability.
